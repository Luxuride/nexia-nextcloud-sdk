# nexia-nextcloud-deck

> Nextcloud Deck client for Kanban boards, stacks, and cards.

Part of the [`nexia-nextcloud-sdk`](https://github.com/Luxuride/nextcloud-rust-sdk) workspace.

## Installation

```toml
[dependencies]
nexia-nexia-nextcloud-deck = "0.2.1"
```

## Features

- `DeckClient`: Full CRUD for boards, stacks, and cards.
- `Board`, `Stack`, `Card`: Strongly typed models for Deck Kanban workflows.

## Example

```rust,no_run
use nexia_nextcloud_deck::DeckClient;

// Manages Deck boards, stacks, cards, labels, and assignments
```
